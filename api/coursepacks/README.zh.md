# 课程单说明

（English: [README.md](README.md)）

这个目录下每个 `*.json` 文件就是一门课程，会出现在 tgarr 的"媒体中心与 PIN → 课程 → 添加课程"里。每种语言一个子目录（`en/`、`de/`、`zh/` ……），指的是材料本身的语言，不是国家。

课程单里**不含任何材料**。它只说明课时在哪里：在互联网档案馆（archive.org），或者在一个公开的 Telegram 频道里。每个用户的 tgarr 自己去那里取文件，tgarr.me 不存放任何内容。

## 怎么做一份

复制 `template.json.example`，改名为 `<语言>/<课程代号>.json`，然后填写：

| 字段 | 说明 |
|---|---|
| `slug` | 课程代号：小写字母、数字和连字符；在所有课程单里不能重复 |
| `title`、`about` | 标题和一两句简介，用材料本身的语言写 |
| `lang` | 材料的语言：`zh-Hans`、`zh-Hant`、`en`、`de` …… |
| `level` | 适合的最小年龄段：`5-8`、`8-12`、`12-16`、`16+`，或 `all` |
| `subject` | 学科：`reading`（母语阅读）、`language`（学外语）、`math`、`science`、`history`、`arts`、`music`、`computing`、`life`、`other` |
| `right` | 材料的授权，见下文。**不写这一项的课程单不会被加载** |
| `credit` | 材料的作者或制作者 |

然后在下面两种来源里**选一种**。

### 来源一：互联网档案馆的条目

```json
"parts": [{"ia": "mcguffeysfirstec00mcgu", "title": "First Reader"}, {"ia": "mcguffeyssecond00mcgu"}]
```

`ia` 是条目编号，也就是 `archive.org/details/` 后面那一串。`parts` 的先后就是课程的顺序；一个条目里有多个文件时，会按文件名的顺序展开成多课。

### 来源二：公开的 Telegram 频道

```json
"channel": "tgarr0", "tag": "#zh_pinyin1", "upto": 120
```

课时就是频道里发的文件，按发布的先后排列。写了 `tag` 时，只取说明文字里带这个标签的帖子，所以一个频道可以放很多门课、很多种语言。标签请以语言开头：`#zh_pinyin1`、`#de_lesen1`、`#es_lectura2`。

发帖的约定：

- 一条帖子一个文件，**文件名就是课时的名字**。
- 说明文字里带上课程标签。
- 按学习的顺序发。
- 频道必须是公开的，并且**不能开启"限制保存内容"**（Restrict saving content），否则谁也读不到。

`upto` 是审核时看到的最后一条帖子的编号，也就是帖子链接末尾的数字（`t.me/tgarr0/120` 里的 120）。课程**只取到这一条为止**。原因是：能在频道里发帖的人，明天可以在任何标签下发任何东西，而它当天就会出现在孩子的屏幕上。所以新增课时后，请把课程单里的 `upto` 调高再提交一次，审核过了新课时才会出现。

## 授权：什么可以收录

一份课程单为它的全部材料声明一种授权：

| `right` | 含义 |
|---|---|
| `PD` | 公有领域：LibriVox 的录音、古登堡计划的文本 |
| `OLD` | 1929 年以前出版、由图书馆扫描的图书 |
| `USGOV` | 美国政府作品 |
| `NOCR` | 收藏它的图书馆声明其不受版权保护 |
| `CC BY`、`CC BY-SA`、`CC BY-NC`、`CC BY-NC-SA`、`CC BY-ND`、`CC BY-NC-ND` | 制作者本人给出的知识共享（Creative Commons）授权 |

公有领域的范围各国不同。这里按美国法律收录，因为 tgarr.me 在美国。

**自己制作的材料**：请以知识共享授权发布，并且**在发布的地方写明**，比如频道简介里或档案馆条目页上。只有自己知道的授权不算授权。

**不收录**，无论课程单怎么写：

- 别人拥有版权的材料：买来的网课、付费平台课程的录屏、仍在版权期内的教材扫描件。
- 档案馆上"免费"的唯一依据是上传者自己打的标记的内容。

## 怎么提交

在 <https://github.com/tgarrpro/tgarr> 提交一个合并请求（pull request），把你的文件放进对应语言的目录。每份课程单在收录前都会被审阅：核对它声明的授权在材料发布处是否确实写明，并查看材料里有没有不适合放进儿童书库的内容。

运行 `python api/test_courses.py` 可以检查这里所有课程单的格式。

课程单是给孩子用的：不收色情内容，不收以残忍为卖点的内容，不收仇恨言论，不收传教布道。

## 两次发版之间的课程单：目录

课程单不必等发版。除了本目录里随镜像发布的课程单，每个安装每天两次向中心取一份课程目录。目录在编写的机器上签名，
签名私钥不在中心；安装只接受签名能被镜像内公钥（`courses.CATALOGUE_KEYS`）验证的目录。目录里的课程单只能指向
Internet Archive 条目，或 `@tgarr0` 频道（必须带标签和 `upto`），别的一律不收。目录提高某个频道课程单的 `upto` 后，
由它生成的课程会自动延伸；目录撤回的课程单会立刻从孩子的清单里拿掉。
设置 `TGARR_UPDATE_CHECK=false` 会连同版本检查一起关闭这项请求。
