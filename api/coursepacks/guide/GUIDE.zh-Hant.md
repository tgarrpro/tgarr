# 在 @tgarr0 發布課程

這個頻道收錄各地志工製作的課程，各種語言都有，提供給使用 tgarr 的家庭。tgarr 是一套免費軟體，能把家裡的一台電腦變成孩子的影音中心和學習書庫。發在這裡的課程，家長在 tgarr 裡按一下就能加入，每一課會從這個頻道下載到自己家的電腦上。

發文之前，請先讀完這一頁。

## 一、可以發什麼

**只發你有權自由分享的教材：**

- 你自己做的：自己錄的聲音、拍的影片、寫的文字和學習單；
- 屬於公有領域的；
- 原作者以創用 CC（Creative Commons）授權釋出的（請寫明是哪一種授權、出處在哪裡）。

**不要發**權利屬於別人的東西：買來的課程、付費平台的上課錄影、仍受著作權保護的課本掃描檔、電影和影集。

除非貼文裡另有說明，發在這裡的內容一律以 **CC BY-SA 4.0** 授權釋出：任何人都可以使用、複製和改作，但要標示你的姓名，並以相同方式分享改作後的作品。如果你想為自己的課程選用另一種創用 CC 授權，請在課程的第一則貼文裡寫明。

課程是給孩子看的。不要有色情內容、為殘忍而殘忍的內容、仇恨言論、廣告，也不要宣揚任何宗教或政黨。

## 二、怎麼發每一課

- **一則貼文放一個檔案**。影片、錄音、PDF、電子書都可以。
- **檔名就是這一課的名稱**。請用數字開頭，順序才清楚：`01 ㄅㄆㄇㄈ.mp4`、`02 ㄉㄊㄋㄌ.mp4`。
- **每則貼文的說明文字都要加上課程標籤**。標籤以課程的語言開頭，接一個簡短的名稱，之後還有續篇的話再加數字：`#zh_zhuyin1`、`#en_phonics1`、`#de_lesen1`、`#es_lectura2`。一個標籤就是一門課。請不要用別人的標籤。
- **照上課的順序發**。tgarr 會依發文的先後順序顯示。
- 單一檔案最大 2 GB。影片建議用 MP4（H.264），聲音用 MP3 或 M4A，文字用 PDF 或 EPUB，這些格式每種裝置都打得開。
- 不要出現別人家孩子的姓名、臉孔和聲音，也不要出現住址和電話號碼。

## 三、發布課程卡

每一課都發完之後，再發一則訊息當作**課程卡**，加上同一個標籤，並寫上這幾行：

```
#zh_zhuyin1
Title: 注音符號入門（上）
About: 三十堂短課，學會聲母、韻母和拼音。
Language: zh-Hant
Ages: 5-8            (5-8, 8-12, 12-16, 16+ or all)
Subject: reading     (reading, language, math, science, history, arts, music, computing, life, other)
Licence: CC BY-SA 4.0
By: 你的名字，或你希望標示的名稱
```

每一行冒號前面的英文和括號裡的選項請照英文寫，其餘內容用課程本身的語言填。`reading` 指用自己的語言學閱讀，`language` 指學外語。繁體中文寫 `zh-Hant`，簡體中文寫 `zh-Hans`。

## 四、之後會怎樣

維護者會把這門課看過一遍：授權有沒有寫明，裡面有沒有不適合放進兒童書庫的東西。看過之後，課程就會列進 tgarr，各個家庭就可以加入了。這是人工作業，可能要幾天。

**之後追加的課不會自己出現**。一門課只列到看過的最後一則貼文為止。追加之後，請帶著標籤發一則簡短的訊息說一聲；看過之後，新的課才會出現。這樣做，是為了不讓沒人看過的東西出現在孩子的螢幕上。

如果後來發現某門課其實不能自由分享，或是不適合孩子，就會從清單上拿掉。

## 五、如果你會用 GitHub

你可以自己寫清單檔再送過來：<https://github.com/tgarrpro/tgarr>，資料夾 `api/coursepacks/`，那裡的說明有寫怎麼做。

謝謝你為別人家的孩子做了一點事。
