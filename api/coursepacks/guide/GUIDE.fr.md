# Publier un cours dans @tgarr0

Ce canal rassemble des cours créés par des bénévoles, dans toutes les langues, pour les familles qui utilisent tgarr : un logiciel gratuit qui transforme un ordinateur de la maison en médiathèque et en bibliothèque d'apprentissage pour les enfants. Un cours publié ici s'ajoute dans tgarr en un clic ; les leçons sont ensuite récupérées depuis ce canal sur l'ordinateur de la famille.

Merci de lire cette page avant de publier.

## 1. Ce que l'on peut publier

**Uniquement des contenus que vous avez le droit de partager librement :**

- ce que vous avez créé vous-même : vos enregistrements, vos vidéos, vos textes, vos fiches d'exercices ;
- ce qui appartient au domaine public ;
- ce que son auteur a publié sous licence Creative Commons (précisez laquelle et d'où vient le contenu).

**Pas** de contenus dont les droits appartiennent à quelqu'un d'autre : cours que vous avez achetés, enregistrements de leçons d'une plateforme payante, manuels scolaires scannés encore protégés par le droit d'auteur, films et séries.

Tout ce qui est publié ici l'est sous licence **CC BY-SA 4.0**, sauf mention contraire dans votre publication : chacun peut l'utiliser, le copier et l'adapter, à condition de vous citer et de partager ce qu'il en fait dans les mêmes conditions. Si vous souhaitez une autre licence Creative Commons pour votre cours, indiquez-le dans sa première publication.

Les cours s'adressent à des enfants. Rien de sexuel, pas de cruauté gratuite, pas de haine, pas de publicité, et pas de prosélytisme pour une religion ou un parti.

## 2. Comment publier les leçons

- **Un fichier par publication.** Une vidéo, un enregistrement audio, un PDF, un livre numérique.
- **Le nom du fichier est le nom de la leçon.** Commencez-le par un numéro pour que l'ordre soit clair : `01 Les voyelles.mp4`, `02 Le son ou.mp4`.
- **Mettez le hashtag du cours dans la légende de chaque publication.** Il commence par la langue du cours, suivie d'un nom court, puis d'un numéro s'il doit y avoir plusieurs parties : `#fr_lecture1`, `#en_phonics1`, `#zh_pinyin1`, `#es_lectura2`. Un hashtag correspond à un seul cours. N'utilisez pas celui de quelqu'un d'autre.
- **Publiez les leçons dans l'ordre où elles doivent être suivies.** tgarr les affiche dans l'ordre de publication.
- Un fichier peut peser jusqu'à 2 Go. Préférez le MP4 (H.264) pour la vidéo, le MP3 ou le M4A pour le son, le PDF ou l'EPUB pour le texte : tous les appareils savent les ouvrir.
- Pas de noms, de visages ni de voix d'enfants qui ne sont pas les vôtres, et pas d'adresses ni de numéros de téléphone.

## 3. Annoncez le cours

Une fois les leçons publiées, publiez un message de plus, la **fiche du cours**, avec le même hashtag et les lignes suivantes :

```
#fr_lecture1
Title: Apprendre à lire, partie 1
About: Trente courtes leçons pour découvrir les sons et lire ses premières syllabes.
Language: fr
Ages: 5-8            (5-8, 8-12, 12-16, 16+ or all)
Subject: reading     (reading, language, math, science, history, arts, music, computing, life, other)
Licence: CC BY-SA 4.0
By: votre nom, ou le nom sous lequel vous souhaitez être cité
```

Les mots placés avant les deux-points et les valeurs entre parenthèses restent en anglais, tels quels, car ils sont lus par un programme et par les responsables du projet ; le reste s'écrit dans votre langue. `reading` désigne la lecture dans sa propre langue ; `language`, l'apprentissage d'une langue étrangère.

## 4. Ce qui se passe ensuite

Les responsables du projet relisent le cours : ils vérifient que la licence est indiquée et que rien n'y est déplacé dans une bibliothèque pour enfants. Le cours est ensuite référencé dans tgarr et les familles peuvent l'ajouter. Ce travail est fait à la main et peut prendre quelques jours.

**Les leçons ajoutées plus tard n'apparaissent pas toutes seules.** Un cours est référencé jusqu'à la dernière publication relue. Quand vous avez ajouté des leçons, publiez un court message avec le hashtag pour le signaler ; elles sont relues, puis elles apparaissent. Ainsi, rien n'arrive sur l'écran d'un enfant sans que quelqu'un l'ait regardé.

Un cours qui se révèle ne pas être libre de partage, ou ne pas convenir aux enfants, est retiré de la liste.

## 5. Si vous connaissez GitHub

Vous pouvez rédiger vous-même le fichier de liste et l'envoyer : <https://github.com/tgarrpro/tgarr>, dossier `api/coursepacks/` ; le guide qui s'y trouve explique comment faire.

Merci de créer quelque chose pour les enfants des autres.
