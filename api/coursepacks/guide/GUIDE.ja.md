# @tgarr0 にコースを投稿するには

このチャンネルには、ボランティアの方々が作ったコースが、さまざまな言語で集まっています。tgarr を使っているご家庭のためのものです。tgarr は、家のパソコンを子どものためのメディアセンター兼学習ライブラリにする無料のソフトです。ここに投稿されたコースは、tgarr でワンクリックで追加できます。レッスンはこのチャンネルから、そのご家庭のパソコンに取り込まれます。

投稿する前に、このページを読んでください。

## 1. 投稿できるもの

**自由に共有する権利があなたにあるものだけです。**

- 自分で作ったもの（自分の録音、動画、文章、プリントなど）
- パブリックドメインのもの
- 作者が Creative Commons（クリエイティブ・コモンズ）ライセンスで公開しているもの（どのライセンスか、出典はどこかを書いてください）

ほかの人が権利を持っているものは**投稿できません**。買った講座、有料サービスの授業を録画・録音したもの、著作権が切れていない教科書のスキャン、映画やドラマなどです。

ここに投稿されたものは、投稿に特に断りがないかぎり **CC BY-SA 4.0** で公開されます。あなたの名前を表示し、作ったものを同じ条件で共有するなら、だれでも利用、複製、改変ができます。別の Creative Commons ライセンスにしたいときは、コースの最初の投稿にそう書いてください。

コースは子どものためのものです。性的な内容、残酷さを見せること自体が目的のもの、ヘイト、広告、特定の宗教や政党の宣伝は投稿しないでください。

## 2. レッスンの投稿のしかた

- **1つの投稿に1つのファイル**。動画、音声、PDF、電子書籍のどれかです。
- **ファイル名がレッスン名になります**。順番がわかるように、先頭に番号をつけてください。例：`01 あいうえお.mp4`、`02 かきくけこ.mp4`
- **どの投稿のキャプションにも、コースのタグを入れてください**。タグは、コースの言語、短い名前、続きがある場合は番号、の順です。例：`#ja_hiragana1`、`#en_phonics1`、`#de_lesen1`、`#es_lectura2`。1つのタグが1つのコースです。ほかの人のタグは使わないでください。
- **学ぶ順番どおりに投稿してください**。tgarr では投稿された順に表示されます。
- ファイルは1つ 2 GB までです。動画は MP4（H.264）、音声は MP3 か M4A、文書は PDF か EPUB をおすすめします。どの端末でも開けるからです。
- 自分の子ども以外の子どもの名前、顔、声は入れないでください。住所や電話番号も入れないでください。

## 3. コースを知らせる

レッスンを投稿し終えたら、もう1つメッセージを投稿します。これが**コースカード**です。同じタグをつけて、次の行を書いてください。

```
#ja_hiragana1
Title: ひらがな その1
About: ひらがなの読み方を学ぶ、短いレッスン30回。
Language: ja
Ages: 5-8            (5-8, 8-12, 12-16, 16+ or all)
Subject: reading     (reading, language, math, science, history, arts, music, computing, life, other)
Licence: CC BY-SA 4.0
By: あなたの名前、または表示してほしい名前
```

コロンの前の英語とかっこの中の値は英語のまま書き、それ以外はコースの言語で書いてください。`reading` は母語で読むこと、`language` は外国語の学習のことです。

## 4. そのあとの流れ

メンテナーがコースを確認します。ライセンスが書かれているか、子ども向けのライブラリにふさわしくないものがないかを見ます。そのあと tgarr の一覧に載り、ご家庭で追加できるようになります。確認は人の手で行うので、数日かかることがあります。

**あとから追加したレッスンは、自動では表示されません**。コースが一覧に載るのは、確認が済んだ最後の投稿までです。レッスンを追加したら、タグをつけた短いメッセージでそのことを知らせてください。確認が済むと表示されます。だれも見ていないものが子どもの画面に届かないようにするためです。

自由に共有できないものだった、または子どもにふさわしくないとわかったコースは、一覧から外します。

## 5. GitHub を使える方へ

一覧ファイルを自分で書いて送ることもできます。<https://github.com/tgarrpro/tgarr> の `api/coursepacks/` フォルダにあるガイドに、やり方が書いてあります。

よその家の子どもたちのために作ってくださって、ありがとうございます。
