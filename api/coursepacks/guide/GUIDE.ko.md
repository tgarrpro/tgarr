# @tgarr0에 강좌 올리기

이 채널에는 자원봉사자들이 만든 강좌가 여러 언어로 모여 있습니다. tgarr를 쓰는 가정을 위한 것입니다. tgarr는 집에 있는 컴퓨터를 아이들을 위한 미디어 센터이자 학습 도서관으로 만들어 주는 무료 프로그램입니다. 여기에 올린 강좌는 tgarr에서 클릭 한 번으로 추가할 수 있고, 수업은 이 채널에서 그 가정의 컴퓨터로 내려받아집니다.

올리기 전에 이 글을 꼭 읽어 주세요.

## 1. 올릴 수 있는 것

**자유롭게 공유할 권리가 있는 자료만 올려 주세요.**

- 직접 만든 것: 직접 녹음한 것, 직접 찍은 영상, 직접 쓴 글과 학습지
- 퍼블릭 도메인에 속하는 것
- 만든 사람이 Creative Commons(크리에이티브 커먼즈) 라이선스로 공개한 것 (어떤 라이선스인지, 출처가 어디인지 적어 주세요)

다른 사람에게 권리가 있는 자료는 **올리면 안 됩니다.** 돈을 내고 산 강의, 유료 플랫폼 수업을 녹화한 것, 아직 저작권이 남아 있는 교과서 스캔본, 영화와 드라마가 그렇습니다.

여기에 올린 자료는 게시글에 따로 밝히지 않는 한 모두 **CC BY-SA 4.0** 라이선스로 공개됩니다. 만든 사람의 이름을 밝히고, 새로 만든 것도 같은 조건으로 공유한다면 누구나 쓰고, 복사하고, 고쳐 쓸 수 있습니다. 다른 Creative Commons 라이선스를 쓰고 싶다면 강좌의 첫 게시글에 적어 주세요.

강좌는 아이들을 위한 것입니다. 선정적인 내용, 잔인함 자체를 보여 주려는 내용, 혐오, 광고, 특정 종교나 정당을 선전하는 내용은 안 됩니다.

## 2. 수업 올리는 방법

- **게시글 하나에 파일 하나.** 영상, 녹음, PDF, 전자책 중 하나를 올립니다.
- **파일 이름이 곧 수업 이름입니다.** 순서를 알 수 있게 숫자로 시작해 주세요. 예: `01 자음.mp4`, `02 모음.mp4`
- **모든 게시글의 설명란에 강좌 태그를 넣어 주세요.** 태그는 강좌의 언어로 시작하고, 짧은 이름을 붙이고, 이어지는 편이 있으면 숫자를 붙입니다. 예: `#ko_hangul1`, `#en_phonics1`, `#de_lesen1`, `#es_lectura2`. 태그 하나가 강좌 하나입니다. 다른 사람의 태그는 쓰지 마세요.
- **배우는 순서대로 올려 주세요.** tgarr는 올린 순서대로 보여 줍니다.
- 파일 하나는 2 GB까지 올릴 수 있습니다. 영상은 MP4(H.264), 소리는 MP3나 M4A, 글은 PDF나 EPUB를 권합니다. 어느 기기에서나 열리기 때문입니다.
- 내 아이가 아닌 아이의 이름, 얼굴, 목소리는 넣지 마세요. 주소와 전화번호도 넣지 마세요.

## 3. 강좌 알리기

수업을 다 올렸으면 메시지를 하나 더 올립니다. 이것이 **강좌 카드**입니다. 같은 태그를 달고 아래 줄들을 적어 주세요.

```
#ko_hangul1
Title: 한글 떼기 1
About: 자음과 모음을 익히고 글자를 읽는 짧은 수업 서른 편.
Language: ko
Ages: 5-8            (5-8, 8-12, 12-16, 16+ or all)
Subject: reading     (reading, language, math, science, history, arts, music, computing, life, other)
Licence: CC BY-SA 4.0
By: 이름, 또는 표시되기를 바라는 이름
```

콜론 앞의 영어와 괄호 안의 값은 영어 그대로 쓰고, 나머지는 강좌의 언어로 적어 주세요. `reading`은 모국어 읽기이고, `language`는 외국어 배우기입니다.

## 4. 그다음에는

관리자가 강좌를 살펴봅니다. 라이선스가 적혀 있는지, 어린이 도서관에 맞지 않는 내용은 없는지 확인합니다. 그런 다음 tgarr 목록에 올라가고, 가정에서 추가할 수 있게 됩니다. 사람이 직접 하는 일이라 며칠 걸릴 수 있습니다.

**나중에 추가한 수업은 저절로 나타나지 않습니다.** 강좌는 확인을 마친 마지막 게시글까지만 목록에 올라갑니다. 수업을 추가했다면 태그를 단 짧은 메시지로 알려 주세요. 확인을 거친 뒤에 나타납니다. 아무도 살펴보지 않은 것이 아이의 화면에 뜨는 일이 없도록 하기 위해서입니다.

자유롭게 공유할 수 없는 자료이거나 아이들에게 맞지 않는 것으로 밝혀진 강좌는 목록에서 내립니다.

## 5. GitHub를 쓸 줄 안다면

목록 파일을 직접 써서 보내도 됩니다. <https://github.com/tgarrpro/tgarr> 의 `api/coursepacks/` 폴더에 있는 안내서에 방법이 나와 있습니다.

다른 집 아이들을 위해 무언가를 만들어 주셔서 고맙습니다.
