# 在 @tgarr0 发布课程

这个频道存放各国志愿者制作的课程，供使用 tgarr 的家庭使用。tgarr 是一个免费软件，能把家里的一台电脑变成孩子的媒体中心和学习书库。发在这里的课程，家长在 tgarr 里点一下就能添加，课时会从这个频道取到自己家的电脑上。

发帖之前请先读完这一页。

## 一、可以发什么

**只发你有权自由分享的材料：**

- 你自己制作的：自己录的音频、视频，自己写的文字、练习册；
- 属于公有领域的；
- 作者以知识共享（Creative Commons）授权发布的（请写明是哪种授权、出处在哪）。

**不要发**别人拥有版权的材料：买来的网课、付费平台课程的录屏、仍在版权期内的教材扫描件、影视剧。

除非帖子里另有说明，发在这里的内容一律以 **CC BY-SA 4.0** 授权发布：任何人都可以使用、复制和改编，但要署你的名，并以同样的方式分享改编后的作品。如果你想为自己的课程选用另一种知识共享授权，请在课程的第一条帖子里写明。

课程是给孩子用的。不发色情内容，不发以残忍为卖点的内容，不发仇恨言论，不发广告，不宣传任何宗教或政党。

## 二、怎么发课时

- **一条帖子一个文件**。视频、录音、PDF、电子书都可以。
- **文件名就是课时的名字**。请以数字开头，让顺序一目了然：`01 声母.mp4`、`02 韵母.mp4`。
- **每条帖子的说明文字里都带上课程标签**。标签以课程的语言开头，接一个简短的名字，如果以后还有续篇再加数字：`#zh_pinyin1`、`#en_phonics1`、`#de_lesen1`、`#es_lectura2`。一个标签就是一门课。不要用别人的标签。
- **按学习的顺序发**。tgarr 按发布的先后显示课时。
- 单个文件最大 2 GB。视频建议用 MP4（H.264），音频用 MP3 或 M4A，文字用 PDF 或 EPUB，这些格式所有设备都能打开。
- 不要出现不是你自己孩子的姓名、面孔和声音，也不要出现住址和电话。

## 三、发布课程卡片

课时发完后，再发一条消息作为**课程卡片**，带同一个标签，并写上这几行：

```
#zh_pinyin1
Title: 拼音入门（上）
About: 三十节短课，学会声母、韵母和拼读。
Language: zh-Hans
Ages: 5-8            （5-8、8-12、12-16、16+ 或 all）
Subject: reading     （reading、language、math、science、history、arts、music、computing、life、other）
Licence: CC BY-SA 4.0
By: 你的名字，或你希望署的名
```

每行冒号前面的英文请照写，后面的内容用课程自己的语言填。`reading` 指母语阅读，`language` 指学外语。简体中文写 `zh-Hans`，繁体中文写 `zh-Hant`。

## 四、之后会怎样

维护者会审阅这门课：授权是否写明，内容里有没有不适合放进儿童书库的东西。通过后它会被收录进 tgarr，各个家庭就可以添加了。审阅是人工做的，可能需要几天。

**之后追加的课时不会自动出现**。一门课只收录到审阅时看到的最后一条帖子为止。追加课时后，请带着标签发一条简短的消息说明，这些课时经审阅后才会出现。这样做是为了保证没人看过的东西不会出现在孩子的屏幕上。

如果事后发现某门课并非可以自由分享，或者不适合孩子，它会被从列表中移除。

## 五、如果你会用 GitHub

你可以自己写课程单文件并提交：<https://github.com/tgarrpro/tgarr>，目录 `api/coursepacks/`，那里的说明写了怎么做。

感谢你为别人家的孩子做了一点事。
